# HedgeDoc


HedgeDoc is an open-source, web-based, self-hosted, collaborative Markdown editor. 

Key features include:

- Real-time collaboration (multiple users can edit together)
- Runs in a browser, so no special client software required 
- Supports diagrams, presentation mode (slides from Markdown via reveal.js), permissions, revisions, etc. 

More information for HedgeDoc can be read at [hedgedoc.org](https://hedgedoc.org/).
