# NextFlow and nf-core

This VM is installed with NextFlow 
together with nf-core.

## Other installations

- wget
- git
- bash
- compilers
- make
- curl
- python3 
- openjdk-17

## How to use

- Pipeline documentation: https://nf-co.re/pipelines
- nf-core tools help: `nf-core --help`

- Nextflow help: `nextflow -h`

- Community: https://nf-co.re/join

## Persistent storage

This VM also contains persistant S3 Storage
which is available for all VMs in the project and
is mounted at `/mnt/project-data`
